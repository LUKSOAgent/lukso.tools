# Agent Outputs

*Directory where agents drop their work for others to read*

## Subdirectories
- `forever-moments/` - Posts, images, IPFS hashes
- `twitter/` - Tweet drafts, engagement reports
- `code-hub/` - Build status, deployment logs
- `heartbeat/` - Check results, status reports

## Naming Convention
`{agent-name}-{task}-{YYYY-MM-DD}.{ext}`

Example: `forever-moments-post-2026-02-11.json`
