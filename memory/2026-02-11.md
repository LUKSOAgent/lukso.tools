### LSP23Factory Source Code Verification
**Verified:** LSP23LinkedContractsFactory.sol on GitHub

**Key finding:** Jean was correct — the controller address IS part of the init_code

**How it works:**
- `_generatePrimaryContractSalt()` creates salt from: user salt + secondary bytecode + postDeploymentModule + calldata
- BUT: The `creationBytecode` passed to `Create2.deploy()` includes encoded constructor params
- Constructor params include the initial controller address
- Different controller = different creationBytecode = different init_code_hash = different UP address

**Conclusion:** Cross-chain same-address deployment requires:
1. Same user-provided salt
2. Same controller address (in creationBytecode)
3. Same other parameters

**Implication for UPage users:** If they don't have their original controller private key, they cannot replicate their UP address on other chains.
