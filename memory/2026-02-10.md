## Testing lsp-factory v4
- Spawned sub-agent to test PR #264 (viem + LSP23 refactor)
- Sub-agent debugging deployment issues on mainnet
- Error `0x9654a854` from LSP23 factory - unknown error signature
- Tried multiple approaches: local build, npm package, different salts
- Funded test wallet with 0.5 LYX: 0x3871e2fa220eAC0fF59a2Deea1dF347AdaEaa71b
- **ROOT CAUSE FOUND:** Error `0x9654a854` = `SecondaryContractProxyInitFailureError(bytes)`
  - Defined in LSP23Errors.sol
  - Thrown when KeyManager proxy initialization fails
  - Happens in `_deployAndInitializeSecondaryContractProxy()` function
  - Common causes: invalid target, already initialized, salt collision
  - The `errorData` bytes contain the specific revert reason from KeyManager
- All contracts verified deployed correctly on mainnet
- Deployment blocked until initialization issue resolved
